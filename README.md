# Inventário Operacional — iPhone e HTTPS

## Versão HTML standalone
Abra `inventario-operacional-iphone.html` pelo **Safari**. Se o iPhone mostrar uma página branca no visualizador de arquivos, toque em **Compartilhar → Abrir no Safari**. Para leitura, use **Ler foto do código** e escolha/tire uma foto do código.

## Publicação HTTPS
Envie os quatro arquivos desta pasta para uma hospedagem estática com HTTPS, mantendo-os na mesma pasta. Abra o endereço no Safari. Nesse modo, **Ler com câmera** solicita a câmera traseira e tenta identificar códigos de barras e QR Codes. Também é possível adicionar à Tela de Início.

A câmera ao vivo depende de HTTPS e da permissão do Safari. O leitor USB e a digitação continuam disponíveis.
